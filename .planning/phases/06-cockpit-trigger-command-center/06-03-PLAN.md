| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-06-10 | Spoofing | Simulate forging ingest traffic indistinguishable from GitHub | medium | mitigate | Synthetic runs carry dedicated negative ids + `simulate:` delivery prefix + trigger_source=reconcile + an audit row — provenance is answerable end to end; simulate drives the same dedupe path (duplicate = harmless, recorded) |
