### T6: Vision Judge agent
- **Files:** `agentrunner/src/agents/vision-judge.ts` (+tests).
- **Steps:** independent session/context (fresh process, no navigator history): fetch step evidence + expected behavior (corpus `uses:` key) → deterministic assertions first (URL/selector/HTTP) → VLM judgment with evidence-citation demand → verdict verified|violated|inconclusive; NO machine-checkable evidence → inconclusive regardless of VLM confidence.
- **Acceptance:** unit tests with fake gateway + fixture evidence: verified path (assertion+VLM agree), violated path, inconclusive path (VLM says pass but no deterministic evidence → inconclusive); context independence (no navigator prompt leakage).
- **Reqs:** AGNT-04, REPT-04 semantics.

## Verification approach

- Per task commit: build + package tests first (Go: `go build ./... && go test <pkgs> -count=1`; TS: `tsc --noEmit && npm test`).
- Cross-task contracts locked here: session env contract (T2/T4 = producer, T3 = consumer); step JSON shape (T3 loop.ts = producer, T2 steps endpoint = consumer, T8 report = renderer); role model map env (T3 reads, T7 documents).
- Full suite at gate: `go test ./... -count=1 -p 1` (shared scratch postgres: never run package binaries in parallel), agentrunner `npm test`, `web` build.

## Threat model (SECR-01, SAFE-01)

- Prompt injection via page content: fenced data blocks + injection-resistance system prompt (T3/T7); page content never executed as instructions (no code-gen eval of page text).
- Credential reach: agent container mounts nothing but e2ai/gateway scoped tokens (T7); boot-time refusal on secret-shaped env (T7).
- Egress: allowlist deny-by-default with violation logging (T7).
- Runaway spend: step ceiling + cost accumulator hard stop + gateway user budget cap (T3/T7) — BudgetExhausted non-retryable everywhere (T1 status machine, T4 MaxAttempts 1).
- Kill switch reachable without deploy: admin surface + API (T2/T8).

## Success criteria (goal-backward)

- Agentic run drives bet-app login + one payment flow on staging → evidence-cited report alongside deterministic run.
- Vision verdicts lacking machine-checkable evidence render INCONCLUSIVE.
- Runaway run hits BudgetExhausted — stops, non-retryable, report says so.
- Sandbox: no credentials reachable; egress beyond allowlist blocked+logged.
- Kill switch stops a mid-flight run without any deploy involved.
