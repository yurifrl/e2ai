# Phase 2 Plan: Plans, approvals, and test derivation

**Phase:** 02-plans-approvals
**Goal:** Human-supervised autonomy: declarative plans with content-hash identity, approval queue gating the pipeline, PR-diff derivation (subset + deterministic drafts, never auto-run), corpus oracle seeded from Playwright specs.
**Research:** .planning/phases/02-plans-approvals/RESEARCH.md (READ FIRST — all decisions locked there)
**Context:** .planning/phases/02-plans-approvals/02-CONTEXT.md

## Locked REST contract (plain JSON under /api/, Phase 1 envelope style — no Connect)

- `GET /api/plans?app=&status=&limit=&offset=` -> `{plans[], limit, offset, next_offset|null}`
- `GET /api/plans/{id}` -> plan + versions[] `{id, version, content_hash, status, sources, created_at}`
- `GET /api/plan-versions/{vid}/content` -> `{content, frontmatter, content_hash, status}`
- `GET /api/plan-versions/{vid}/diff` -> `{diff, base_version_id|null}`
- `GET /api/approvals?status=` -> queue + recent decisions
- `POST /api/plan-versions/{vid}/approve|reject` body `{notes?}` -> 200 | 401 no identity | 409 superseded hash
- `POST /api/apps/{id}/plans-sync` -> `{synced, added, changed, unchanged}`
- `GET /api/corpus?app=` -> `{behaviors[], learnings[]}`
- `POST /api/corpus/learnings/{lid}/promote|dismiss`
- `GET /api/runs/{id}/plan-resolution` -> `{selected[{plan_id,version,hash,source}], excluded[], diff_truncated}`
- `POST /api/runs/{id}/derive-draft` -> `{queued}`

## Wave 1 — pure cores (parallel, disjoint packages)

### T2: Plan parse + validate + format doc
- **Files:** `api/internal/plans/{parse.go,validate.go,parse_test.go,validate_test.go}`, `docs/plans/format.md`.
- **Steps:** Frontmatter parse (goccy/go-yaml): id regex `^[a-z0-9][a-z0-9-]*-v\d+\.\d+\.\d+$`, app ref, surfaces non-empty subset, trigger enum (on-deploy|on-demand|nightly), optional pr-filter paths globs, optional timeout default 10m. Steps: numbered, each with falsifiable `judge:` (numeric bound | state assertion | `uses:` ref); `uses:` keys; `on-failure:` enum (continue|diagnose, default stop). Strict: unknown keys rejected. `content_hash = sha256(normalize(bytes))` (CRLF->LF, strip trailing ws). Validation takes narrow interfaces (`AppLookup`, `BehaviorStatus`) so tests are pure; adapters land in T4. Tautology lint: derived plans with `sources:` empty or all diff-derived -> reject (only when plan carries `derived: true`); diff-identifier tokens in judge lines -> flag list returned (not rejected).
- **Acceptance:** table tests per research §Pattern 1 rule set incl. all reject cases + normalize cases; `go test ./internal/plans/`.
- **Reqs:** PLAN-01, DERV-03.

### T3: Corpus store + seed + promotion
- **Files:** `api/internal/corpus/{store.go,seed.go,seed_test.go,store_test.go}`.
- **Steps:** Store CRUD over corpus_behaviors + corpus_learnings (pgx). Seed: fetch Playwright spec files from app repo (extend github client with `GetFile`) for the app's configured specs dir (config key `corpus_specs_dir`, default `apps/bet-client/e2e/`); parse test/describe titles -> behavior key `PWSPEC-<TESTNAME>`, description = title + expect summary, provenance `{kind: playwright-spec, path, commit}`, status `verified` (human-authored trusted seed); idempotent by (app_id, key). Promote: learning -> behavior copy with provenance.kind=learning + verified_by; dismiss marks learning. NO self-mutation paths: writes only via these functions.
- **Acceptance:** scratch-postgres tests: seed idempotency, promote copies provenance, learnings append-only; `go test ./internal/corpus/`.
- **Reqs:** CORP-01, CORP-02.

## Wave 3 — approvals machine (T6 owns main.go) || derivation package (T7, no main.go)

### T6: Approval state machine + REST
- **Files:** `api/internal/approvals/{machine.go,machine_test.go}`, `api/internal/approvals/http.go`, `api/cmd/e2ai-api/main.go` (approvals routes).
- **Steps:** Machine transitions per research §Pattern 4 (draft->pending on submit; pending->approved|rejected; approve sets version approved + supersedes previous approved version of same plan id; 409 if approving non-pending/superseded hash). Identity: read httpx context; reject 401 when identity missing; NEVER accept UserOf dev-fallback "you" for approval writes (check header presence, not fallback value). Attribution row per decision (plan_approvals). REST: queue + decide endpoints per contract.
- **Acceptance:** machine table tests (every transition + illegal ones); REST tests with/without identity headers; 409 path; `go test ./internal/approvals/`.
- **Reqs:** APPR-01, APPR-02.

### T7: Derivation package — compare, mapping, drafting
- **Files:** `api/internal/platform/github/client.go` (+`Compare`, `ListPRFiles`), `api/internal/derive/{scope.go,draft.go,derive_test.go}`.
- **Steps:** Compare via 3-dot basehead + `pulls/{n}/files` preference (PR resolution via ListPullsForCommit when pull_requests empty); truncation surfaced (`diff_truncated`). Scope mapping per research §Pattern 5: direct (pr-filter glob vs changed files), indirect (corpus provenance path overlap), else-excluded; no pr-filter -> always included; priority direct > indirect > most-recent-failed. Deterministic draft generator (P2 stand-in for the P3 Plan Author agent — same job seam): for the mapped subset, emit draft plans seeded from overlapping corpus behaviors — one step per behavior, `judge: uses: <behavior-key>`, `sources: [corpus:<key>]` (never diff-only); writes plan_version rows status `draft` via the same upsert path as sync (never pending without human). Tautology guard: drafts carry non-empty independent sources.
- **Acceptance:** mapping table tests (direct/indirect/excluded/priority); draft tests assert sources provenance non-diff + draft status; fake-GitHub compare/files tests incl. truncation flag; `go test ./internal/derive/ ./internal/platform/github/`.
- **Reqs:** DERV-01, DERV-02, DERV-03.

## Success criteria
- Invalid plans rejected at ingest with actionable errors; content-hash identity everywhere (APPR-01).
- Approval queue + attributed decisions; unauthenticated writes impossible; 409 on superseded.
- Pipeline executes approved versions only; changed plans keep running last approved; drafts never execute.
- Real-PR derivation yields prioritized subset + corpus-seeded drafts with independent sources (tautology-guarded).
- Corpus seeded w/ provenance; learnings promote/dismiss human-only.
